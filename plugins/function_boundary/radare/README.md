# `radare_boundaries` — radare2 function boundary discovery

Discovers function start/end addresses with radare2 and posts them to
`function_boundary`.

- **Base image:** `python:3.11-slim` (self-contained)
- **Weight:** `0.85`
- **Competes with:** [`../angr/`](../angr/README.md) and [`../binja/`](../binja/README.md)
